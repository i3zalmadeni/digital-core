
## الطباعة الموحدة ورمز التحقق (0031)
`site/assets/report-kit.js` أداة طباعة واحدة لكل أنظمة النواة: صفحة A4 بترويسة (كليشة الوزارة، شعارا النواة ووزارة التعليم، التاريخ والعام ورقم التقرير) وتذييل (النظام المُصدِر، رقم الصفحة، النواة الرقمية، رمز QR) في كل صفحة.
- كل نظام يحمّلها ويستدعي `ReportKit.install({ system, systemName, root })`، فيصدر أي `window.print()` بالهوية الموحدة.
- كل تقرير يُسجَّل في `core_report_issues` بنسخة ثابتة. صفحة `verify/` تعرض بيانات الإصدار للجميع، والنسخة الكاملة للمُصدِر ومدير النواة ومن له صلاحية في النظام المُصدِر (أو للجميع إن صدر بخيار `publicFull`). تقرأ أيضًا تقارير المجتمع المهني السابقة (`pc_report_issues`).
